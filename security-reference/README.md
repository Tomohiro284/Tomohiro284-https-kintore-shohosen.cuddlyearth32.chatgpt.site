# 導入範囲

添付19ファイルを attachment-bundle.json の files に元の名前と全文で保存しています。実行はしません。Python WSGI、Gunicorn、Nginx、Windows Defenderの設定は現在の静的Vercelサイトでは実行できません。また参照される ultra_guard 本体が添付に含まれていないため、サーバー用キットとしては未完成です。

vercel.json はCSPによる外部スクリプト・接続・フレームの制限、クリックジャッキング対策、MIME判定制限、参照元情報抑制、不要な端末権限の禁止、HTTPS強制を設定します。管理パスにはnoindexヘッダーを設定します。認証の代替にはなりません。

現在広告タグは未設定です。広告導入時は公式配信先を確認してCSPを必要最小限変更し、動作検証してください。外部広告は現状遮断します。

この設定は端末のウイルス検査や全攻撃・情報漏えいの完全防止を保証しません。GitHub/Vercelのアカウント保護、WAFやレート制限は提供元で別途設定が必要です。
